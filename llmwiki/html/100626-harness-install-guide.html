Trường hợp A — Project mới hoàn toàn

Nằm trong /new-project-setup (bước 3 của skill đã được cập nhật). Chạy tay thì đúng 4 khối lệnh này:

# 0. (nếu chưa pull template) — sync-template tự lo, hoặc tay:
git clone -b orca git@github.com:rheinmir/setup.git /tmp/tpl
cp -R /tmp/tpl/harness /tmp/tpl/llmwiki ./ && rm -rf /tmp/tpl

# 1. Cài harness — script tự detect mode NEW, dựng khung wiki + copy toàn bộ:
bash harness/scripts/install-harness.sh .

# 2. Kích hoạt L2 git gate (một lần mỗi máy):
pipx install pre-commit && pre-commit install

# 3. Smoke check — lệnh này PHẢI bị chặn (exit 2):
echo '{"action":"write","file_path":"llmwiki/raw/x.md"}' | python3 harness/validators/no_write_raw.py

Trường hợp B — Migrate project đã onboard

Wiki cũ thường có "nợ" (file thiếu ## Origin, index lệch). Script không bật chặn mù: nó audit trước, exit 3 kèm danh sách nợ, bạn trả nợ rồi chạy lại.

⚡ Cách lười (khuyến nghị): trong phiên Claude Code, gọi /harness-update — Claude tự chạy installer, tự backfill nợ (thêm ## Origin từ git log, sửa index), lặp tới khi sạch rồi báo cáo. Các lệnh dưới là bản chạy tay tương đương:

# 1. Chạy installer ngay tại root project (script tự clone template nếu repo chưa có harness/):
bash harness/scripts/install-harness.sh .
#   → mode: MIGRATE — settings.json được MERGE (backup .bak.*, giữ nguyên hook bạn tự thêm)
#   → rc=3 nếu CÓ NỢ, kèm danh sách in thẳng ra terminal + harness/metrics/baseline-YYYY-MM-DD.json

# 2. Trả nợ theo danh sách (ví dụ):
#   [R2] concepts/old-thing.md thiếu '## Origin'  → mở file, thêm section Origin (backfill "legacy")
#   [R3] THIẾU trong index: concepts/old-thing.md → thêm row vào wiki/index.md

# 3. Chạy lại để xác nhận sạch — lặp tới khi rc=0:
bash harness/scripts/install-harness.sh .

# 4. Kích hoạt L2 + smoke:
pipx install pre-commit && pre-commit install
echo '{"action":"write","file_path":"llmwiki/raw/x.md"}' | python3 harness/validators/no_write_raw.py  # phải exit 2

Sau khi cài — cả 2 trường hợp như nhau

Những gì tự chạy ngầm từ giờ (0 token, 0 lệnh phải nhớ)

  • Mỗi tool call: PreToolUse chặn ghi raw/ + sai folder · PostToolUse bắt thiếu ## Origin · audit JSONL tự ghi
  • Kết thúc lượt: Stop hook chặn nếu index lệch · SessionEnd tự append log.md
  • Mỗi commit: pre-commit chạy lại validators + wiki-health — agent vendor nào cũng bị gate

🎬 Tour — xem hệ thống làm gì trước khi tin nó

  • Tầng 1 (tự động): cuối install-harness.sh có bảng "Harness tự kiểm" — 3 rule phải hiện BỊ CHẶN ✓
  • Tầng 2 (1 lệnh): bash harness/scripts/tour.sh — máy diễn đủ 5 cảnh trong sandbox /tmp, tự dọn: chặn ghi raw/ (cả đường bash), ép Origin, bắt sai folder, bắt index nói dối, audit JSONL tự ghi
  • Tầng 3 (trực quan nhất): gọi /harness-tour trong phiên Claude Code — Claude cố tình vi phạm 3 rule trên project thật, bị chặn sống, tường thuật từng phát cắn, rồi tự dọn demo
